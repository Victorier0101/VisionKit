# Face Landmarker model

`face_landmarker.task` is the MediaPipe Face Landmarker float16 model downloaded from Google's official model storage:

https://storage.googleapis.com/mediapipe-models/face_landmarker/face_landmarker/float16/1/face_landmarker.task

It is loaded by the browser and used locally. VisionKit does not upload camera frames, landmark arrays, images, or video.
